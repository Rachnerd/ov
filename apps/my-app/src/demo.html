Getting started

Using an atom

Import the barrel once in your entry module, then drop atoms anywhere in your HTML: 
import 'openvalue-atoms';

<ov-button variant="primary" size="lg">
  <ov-icon slot="start" name="plus"></ov-icon>
  Create project
</ov-button>

<ov-input placeholder="Search…">
  <ov-icon slot="prefix" name="search"></ov-icon>
</ov-input>
Toggle dark mode anywhere in your tree — the atoms follow automatically: 
// Respect OS
document.documentElement.removeAttribute('data-theme');

// Force light / dark
document.documentElement.setAttribute('data-theme', 'dark');

// Scoped to a subtree
<div data-theme="dark">
  <ov-button>Always dark</ov-button>
</div>
